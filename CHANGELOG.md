## [0.1.0] - 2026-09-06

### Added

- Recursive Multicall3 `aggregate3` decoding.
- Common ERC selector and ABI decoding.
- Dynamic arrays, tuples, strings, and byte values.
- Optional RPC inspection, proxy resolution, token metadata, verified Sourcify ABIs, and `eth_call` execution.
- Sourcify 4byte candidate discovery with explicit confidence levels.
- Return-value, standard-revert, and verified custom-error decoding.
- Plain-English and structured JSON reports.
- Python, PowerShell, Command Prompt, and Bash entry points.
- Local preflight checks and unit tests.
